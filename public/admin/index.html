iPhone key

Copy this now. It is shown only once; if you lose it, make a new one.

Set it up on your iPhone

  1. One helper shortcut (holds the key). Shortcuts app → + → name it Ayesha status. Add the action Get Contents of URL, URL https://ayeshanoor.fun/api/status. Tap the arrow to show more: Method POST · Headers: add X-Status-Key = your key · Request Body JSON: add a Text field named set and set its value to the Shortcut Input variable.
  2. Wi‑Fi automations. Automation tab → + → Wi‑Fi → pick your home network → Run Immediately (and turn off "Notify When Run"). Actions: a Text action with home, then Run Shortcut → Ayesha status. Do the same for school (school) and work (work).
  3. Location automations (backup, and for leaving). + → Arrive → choose the place → Run Immediately → Text home / school / work → Run Shortcut Ayesha status. Then Leave for each place with leave-home, leave-school, leave-work (these only clear the status if it came from that place).
  4. Car Bluetooth (driving). + → Bluetooth → your car → Is Connected → Run Immediately → Text driving → Run Shortcut Ayesha status. Then a second one with Is Disconnected and leave-driving (it only clears "driving", so it never wipes "at school").
  5. Your manual button (optional). New shortcut My status: Choose from List with free, free-school, chat, busy, clear → Run Shortcut Ayesha status. Add it to your Home Screen for one-tap changes (like "free at school" between classes).

Words it understands: home, school, free-school, work, free, chat, busy, driving, leave-home, leave-school, leave-work, leave-driving, clear. Your phone works out where you are; the site only ever receives the word.
